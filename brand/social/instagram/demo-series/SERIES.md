## Daily workflow

### Morning / before post
1. Open Part folder for today under `brand/social/instagram/demo-series/`
2. Edit captions + burn-in if needed
3. In IG: create Reel → upload mp4 → **add trending audio** matched to the table
4. Caption template:

```
Features on BarathX · Part {N}
{one-line hook}

Save this. Part {N+1} drops tomorrow.
→ barathx.com

#BarathX #IndiaApp #BuildInPublic …
```

5. Post **once** (evening IST peak ~20:00 preferred for Reels). Carousel schedule can still run separately if desired — don’t spam 3 demo Reels/day.

### End of day (EOD) — Instagram insights
Open IG Professional dashboard for @getbaratx and log:

| Field | Note |
|-------|------|
| Date / Part # | |
| Reach | |
| Plays / views | |
| Avg watch % / retention | |
| Likes / comments / shares / saves | |
| Hook (0–3s) drop-off | High drop = weak cold open |
| Audio used | Name + why |
| What worked | |
| What flopped | |
| Change for tomorrow | e.g. faster hook, different music, more face/UGC |

Log file: `brand/social/instagram/demo-series/INSIGHTS_LOG.md` (append daily).

### Insight → next Reel rules
- **Low retention <25%** → shorter Part, harder first-frame text, music drop earlier  
- **High saves** → make a “checklist” style Part next  
- **High shares** → more debate/controversy Part  
- **Comments ask “how do X?”** → that X becomes next Part  
- **Faah-style audio wins** → keep for hot-take Parts; use calmer audio for Profile/Theme
