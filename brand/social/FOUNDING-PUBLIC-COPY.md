# Founding 100 — public vs private copy

## Public (everywhere until they earn it)

```
100 Founding spots, earned by opening a debate that gets real engagement, not by signing up.
```

Use this on: bios, outreach, scheduled Social drafts, landing, Arenas, first-session, Rewards (before payable).

**Never** put ₹150 / rupee amounts in public Founding copy.

## Private (in-product only, after earned)

When status becomes `payable`:

```
You're in. Small thank-you on the way — ₹150, no strings.
```

When `paid`:

```
You're in. Thank-you sent — ₹150, no strings.
```

## Scheduled Social drafts — replace-up-front

If a draft mentions Founding cash, First 100 · ₹150, or “get ₹150 for…”, rewrite to the public line above. Prefer identity + exclusivity over incentives.

Example rewrite:

- Before: `First 100 get ₹150 for opening a live`
- After: `100 Founding spots, earned by opening a debate that gets real engagement, not by signing up. → barathx.com`
