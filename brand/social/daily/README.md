# Daily social packs (WhatsApp + X)

Each morning folder: `brand/social/daily/YYYY-MM-DD/`

Contains:
- `PACK.md` — paste-ready WhatsApp community + X copy
- images for that day

**Cadence:** 1 WhatsApp community post + 1 X post per day (IST morning preferred).

**How to get the reminder:** Ask the Cursor agent each morning, or set a **Cursor Automation** (daily ~9:00 IST) with prompt:

> Prepare today’s BarathX WhatsApp community + X daily pack: short copy + image, save under brand/social/daily/YYYY-MM-DD/, follow CONTENT-RULES (BarathX spelling, signup CTA, no Founding ₹).
