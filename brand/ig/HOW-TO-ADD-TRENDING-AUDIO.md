# How to add trending Instagram audio (required)

Graph API **cannot** search or attach Instagram’s music library.
Do this in the IG app for every Reel:

1. Open Instagram → create **Reel**
2. Upload the video from `brand/ig/posted/YYYY-MM-DD/*.mp4` (or Files)
3. Tap **Audio** at the top
4. Search a trending track (or pick from **Trending**)
5. Trim audio to match the clip
6. Paste caption from `CAPTIONS-*.md`
7. Share

Tip: upload the Reel **muted / with weak bed**, then replace with trending audio in-app so the sound sticker shows (better reach).
