# IG format rotation — product launch (BarathX)

**Rule:** Do **not** reuse the same grunge pack every post. Pick format from what’s working for **early product launches** *and* fits BarathX (sided debate, early, honest). Spelling always **BarathX**.

Checked ~2026-08-10 — refresh before major campaigns.

## What’s working for launches (fold in, don’t copy blindly)

| Job | Format that wins now | Fits BarathX when… |
| --- | --- | --- |
| Discovery / new eyes | **Reels** 15–45s (reach engine) | Phone-cam or screen-record of a **real** Live / Square moment; problem→mechanic in first 3s; text on screen (mute) |
| Saves / “how it works” | **Carousel** 6–8 slides (save engine) | Hook → mechanic steps → soft CTA. Visual system can rotate (grunge is *one* option) |
| Big launch beat | **Reel first, carousel ≤24h later** | Same story twice: awareness then depth |
| Trust / early product | **UGC-style / raw** (not studio polish) | Founder talking to camera; real UI; no fake scale |
| Soft ask | Comment **BX** / reply for link | Never “Join now!!” |

India extras that help: short completion-friendly Reels, Hinglish/regional hook when natural, save-oriented CTA (“send this to your group chat”), few precise hashtags.

## Format picker (use every run)

1. If Drive `Social Draft` names a format or includes assets → **use that**.
2. Else if we have a **real** debate clip / screen recording from founder → **Reel** (launch-style UGC).
3. Else if the post’s job is explain / save → **carousel** with a **non-repeated** visual system (see kit below).
4. Else if nothing real this week → **skip inventing video**; post a mechanic carousel *or* do nothing if standing schedule is paused.
5. **Never** default to the same 6 grunge slides three times a day.

## Creative kit (rotate — do not lock to one)

| System | Use for | Notes |
| --- | --- | --- |
