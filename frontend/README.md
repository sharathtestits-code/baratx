# IndiaVoice frontend (demo)

React (Vite) app for signup / login / dashboard.

## Run

```
npm install
npm run dev
```

Open the URL it prints (usually http://localhost:5173).

Requires the backend running on http://localhost:8000 (see `../backend/README.md`).
If you change the backend's port, update `VITE_API_BASE` in `.env` to match.
